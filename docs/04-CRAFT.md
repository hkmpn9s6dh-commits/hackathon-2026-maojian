# 04 做法（能复算的部分）

## 管线

```
story.py ──┬─→ render.py --prep     去水印 → 放大 2400×1600 → 锐化 → keyframes/plate/
           ├─→ render.py --seg k/4  调色（整张底本做一次）+ 窗口运镜 + 颗粒 + 暗角 + 字卡 + 字幕
           ├─→ audio.py             旁白（edge-tts）+ 16 个合成音效 + drone/脉冲/垫音 → out/audio.wav
           ├─→ scripts/master_audio.py  两遍 loudnorm → −16 LUFS / TP ≤ −1.5
           ├─→ render.py --concat   剥音轨 → 拼 → 挂母带 → out/maojian.mp4
           ├─→ render.py --shotlist docs/02-SHOTLIST.md（由 story 生成）
           └─→ build_site.py        作品页 + 字体子集 + 封面 + 六帧
```

## 五个技术决定

1. **调色放在底本上，不放在帧上。**
   分级是逐点运算，与帧无关。第一版逐帧调色 0.58 s/帧（4 段并行实测约 1.35 s/帧），
   改成「整张底本调一次、再裁窗口」后 0.114 s/帧，快 5 倍，画面完全等价。

2. **水印是裁掉的，不是盖掉的。**
   生成器在右下角压「AI生成｜WORKBUDDY」。先切掉底部 96 px（1024 高的 9.4%），
   再等比放大到 1600 高、中心裁到 2400 宽。切掉的部分正好落在 16:9 取景的余量里。

3. **字卡自带底版。**
   深色工业画面里，单独的白字数字压不住（第一版「1,150」直接糊在冲压机上）。
   改成「深色圆角底版 + 左缘一道暖色细边」，字卡从「贴纸」变成「版式」。
   字幕另给一条从 y=640 起的底部渐层，最深 0.72，实测局部对比 ≥ 3.0。

   > 这句「暖色细边」曾经是假的：PIL 的 RGB 被直接盖到 cv2 的 BGR 帧上，
   > 琥珀 `(202,150,92)` 渲成了蓝色，一路没人发现。现在换序之后才是暖色。
   > 另：底版右缘的 96 px 渐隐只作用在底版图层，字不参与渐隐（见 06-REVIEW 第 12 条）。

4. **分段渲染，但分段必须剥音轨。**
   每段都带「从 0 开始」的音轨，直接拼会串音（第一版就是这么错的）。
   现在流程是：每段 `-an` 剥掉 → concat 拼视频 → 再把母带挂回去。
   顺带的好处：母带只编码一次，不跨段丢帧。

5. **可变字体不吃。**
   `NotoSansSC-VF.ttf` 在 PIL 里取到的是默认实例（偏细），英文副字幕看着像灰线。
   换成静态 `Noto Sans SC (TrueType).otf` 后字重才对。

## 验收（`py -3 verify.py`，44 条）

| 组 | 查什么 |
|---|---|
| story 自洽 | 时长和、总帧数、起点单调、每镜有论证、枚举合法、片长区间 |
| 底本 | 18 张齐备、2400×1600 且非纯色、水印带已切 |
| 字体与版式 | 字体可加载、字幕宽度 ≤1180、左边界与底边留白 |
| 旁白 | 10 条已合成、不超窗口、互不重叠、最多跨一镜且不压落版 |
| 容器 | 1920×1080、24fps、时长 156±0.15、60–180s、h264/yuv420p、bt709、有音轨、AAC 48k 立体声、码率 |
| 响度与动态 | −17.5…−14 LUFS、TP ≤ −1.0、峰均比 6–20 dB、无削波、立体声 |
| 画面抽样 | 首帧近黑、黑场区间、落版有字、片尾淡出、每镜非纯色/曝光/切点 |
| 版式实测 | 字幕与字卡按**字形掩码**双渲比对比（≥4.5，WCAG AA） |
| 文档 | 分镜表存在、覆盖全镜、含全旁白、总长一致 |
| 交付 | 体积 ≤500 MB、打印 sha256 |

合计 **44 条**（本机实测 44/44）。

**两个判据本身也改过**：
- 第一版用「局部亮度 p90/p10」量字幕，量到的是画面反差不是可读性（1.21 也判过）；
  改成按 sprite 的 alpha 取字形、再与无字帧同一批像素比亮度。
- 第一版把 148.8 s 的采样判成「纯色/曝光 0」——那是设计的黑场。
  现在黑场区间写进 `story.BLK0/BLK1`，渲染与验收共用同一对数字。

## 已知的弱项

- **卡车细节**：远景靠雾、逆光、剪影；近景靠微距。全片没有一辆车是正面大全景——
  这是有意避开生成器在车头比例上的软肋，不是风格选择。
- **第 17 镜（海外）**：仍是长头车（conventional cab）。真实出口市场（东南亚、非洲、拉美）
  长头与平头并存，画面可信；但如果评委按「中国商用车＝平头」的标准看，会有轻微违和。
- **没有人物**：全片无演员。好处是不会出现 AI 人脸崩坏；代价是少了一层「人」的温度。
  《01-IDEA》里记了为什么这么选。
